# FOKUS-BOX

Die FOKUS-BOX ist ein interaktives System zur Förderung der Konzentration. Ziel des Projekts ist es, Ablenkungen zu reduzieren und den Nutzer durch visuelle, akustische und physische Rückmeldungen beim fokussierten Arbeiten zu unterstützen.

Das System verwendet einen Ultraschallsensor zur Erkennung von Annäherungen sowie einen Servomotor, eine RGB-LED und einen Buzzer, um unterschiedliche Reaktionen auszulösen. Je nach Situation zeigt die Box verschiedene „emotionale Zustände“ wie Gelassenheit, Aufmerksamkeit, Warnung oder Vertrauen an.

Das Projekt wurde im Rahmen des Moduls Interactive Systems (IntSys) entwickelt.

## Verwendete Komponenten

- Arduino Uno
- HC-SR04 Ultraschallsensor
- Servo-Motor
- RGB-LED
- Buzzer
